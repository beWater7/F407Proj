# Vendored kconfig-frontends (Linux-style menuconfig)

Binaries from Ubuntu package `kconfig-frontends-nox` 4.11.0.1 (amd64).

Used by `scripts/menuconfig.sh` so `make menuconfig` looks like Linux
kernel `make menuconfig` (blue dialog UI).

Needs system `libncursesw.so.6` (usually already installed).

Alternative (system-wide):
```bash
sudo apt install kconfig-frontends-nox
```
